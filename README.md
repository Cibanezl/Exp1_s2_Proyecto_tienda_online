# Proyecto Tienda Online - Sumativa 2

**Asignatura:** Desarrollo Frontend I (PFY2201)  
**Estudiante:** Carlos Ibáñez  

## Descripción
Aplicación web de comercio electrónico que consume un catálogo local vía JSON y Fetch API, con carrito de compras interactivo, filtro de búsqueda en tiempo real y diseño responsivo adaptado con Bootstrap 5.
